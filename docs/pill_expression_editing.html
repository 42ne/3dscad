Pill / Expression Editing — behavior spec

Стан на: 2026-06-07. Гілка exp8. Відлагоджено на не-табличних primitive-картках.

Документ описує правила рендерингу, ховеру та редагування числових «піллів» у рядках параметрів шейп-карточки, а також у VAR/PAR expression-полях. Логіка винесена у реюзабельний ExpressionPillLayout.

1. Структура рядка параметра (Cube)

Кожен параметр (X, Y, Z) займає один горизонтальний рядок поза рамкою картки. Рядок ділиться на дві зони:

rowRect ┌─────────────────────────────────────────────────────┐ │ LABEL │ FIELD AREA (expression / pills) │ │ 14px │ +2px gap rowWidth - 14 - 4px │ └─────────────────────────────────────────────────────┘ fieldRect = rowRect.adjusted(+16, 0, -4, 0)
ЗонаШиринаВміст
LabelkLabelW = 14 px Букви «X», «Y», «Z». Без «=». Колір numLabelText.
FieldrowWidth − 14 − 4 px Всі піллі та оператори вираження.

Для інших не-табличних шейпів використовується той самий ExpressionPillLayout, але поле починається після PrimitiveParamLabelArea: мітка ширша і містить «=».

Для VAR/PAR рядків ExpressionPillLayout застосовується лише до області після знаку «=» (variableExpressionTextRect). Ім'я змінної або параметра залишається окремою RenameZone і не входить у expression field.

2. Розбивка виразу на спани (ExpressionTextSpan)

Функція expressionSpansInTextRect(fieldRect, expression, metrics) повертає вектор спанів. Кожен спан:

struct ExpressionTextSpan {
    QString text;    // "25", "+", "230", "(", "a", …
    int start;       // позиція в рядку expression
    int length;      // довжина підрядка
    QRectF rect;     // bounding rect у scene coords (з ±4px паддінгом для числел)
    bool number;     // true → цифровий літерал або ident з десятковим значенням
};
Важливо: expressionSpansInTextRect додає ±4 px горизонтального паддінгу до rect.width() для числових спанів. Рендерер та менеджери ховеру усувають цей паддінг і будують pillRect вручну.

Формула pillRect

// Скрізь однакова (renderer, hoverManager, hitTestManager)
const qreal textW    = span.rect.width() - 8.0;   // strip ±4px padding
const qreal pillW    = textW + 4.0;                // +2px кожного боку
const qreal pillLeft = qMax(fieldRect.left(), span.rect.left() + 2.0);
QRectF pillRect(pillLeft, fieldRect.top(), pillW, fieldRect.height());

Приклади розбивки

expressionСпани (text / number)Тип поля
25 [{«25», true}] Simple (1 пілл)
25+230[{«25», true}, {«+», false}, {«230», true}]Complex (2 піллі)
w/2 [{«w», false}, {«/», false}, {«2», true}] Complex (1 пілл)
a+b [{«a», false}, {«+», false}, {«b», false}]No-pill (лише текст)

Ознака simpleNumber = (spans.size() == 1 && spans.first().number) перемикає кілька гілок поведінки нижче.

5. Scroll-зони (cyan підсвічування)

Функція hoverScrollZoneRect повертає прямокутник для cyan-рамки, яка показується при наведенні з Ctrl або при скролі:

УмоваПовертає
Cursor on a specific number pill (span.start == numStart) pillRect(span) — cyan рамка навколо одного пілла
No specific pill match (між піллями або simpleNumber) fieldRect — cyan рамка навколо всього поля

Де numStart = m_activeShapeParameterNumberStart, встановлюється updateActiveShapeParameterControl при русі миші з Ctrl.

6. Inline-редактор та збереження

При кліку викликається SceneTreeInlineEditor::startInlineExpressionEdit(target). Текстовий input ставиться на target.editRect і показує target.expression (або окреме число, або повний вираз).

При підтвердженні (Enter):

// SceneTreeInlineEditor.cpp
case ExpressionEditTarget::ShapeParameter:
case ExpressionEditTarget::Variable: {
    QString exprToSave = newExpression;
    if (target.spanStart >= 0 && !target.fullExpression.isEmpty()) {
        // Splice: замінити лише підрядок [spanStart, spanStart+spanLength)
        exprToSave = target.fullExpression.left(target.spanStart)
                   + newExpression
                   + target.fullExpression.mid(target.spanStart + target.spanLength);
    }
    // emit shapeParameterExpressionEdited(...) або variableExpressionEdited(...)
}

7. Структура ExpressionEditTarget (повна)

struct ExpressionEditTarget {
    enum Kind { None, Transform, ShapeParameter, Variable,
                ModuleCallArgument, PolyhedronParticipation, Polygon2DPoint };
    Kind    kind        = None;
    QRectF  hoverRect;          // жовта рамка; QRectF() = не показувати
    QRectF  editRect;           // куди розміщується inline input
    QString label;              // рядок у tooltip (напр. "Shape X")
    QString expression;         // те, що показується в input
    int     nodeId      = 0;
    int     secondaryId = 0;    // для ShapeParameter: індекс параметра (0=X,1=Y,2=Z)
    // Sub-expression fields (ExpressionPillLayout fields):
    QString fullExpression;     // повний вираз рядка
    int     spanStart   = -1;   // >= 0 → splice-збереження
    int     spanLength  = 0;
};

9. Реюзабельний layout-клас

Формула pillRect та базова логіка simple/complex винесені в ExpressionPillLayout. Клас не знає про конкретну картку: будь-який рендерер або менеджер передає QRectF fieldRect, QString expression і QFontMetricsF, після чого отримує однакову геометрію та hit-test поведінку.

Зроблено: ExpressionPillLayout інкапсулює:
  • fieldRect як готову область виразу;
  • spans() → вектор ExpressionTextSpan;
  • pillRectFor(span);
  • visiblePillRectFor(span) з обрізкою по полю;
  • spanAt(scenePos) → знайдений числовий span;
  • логіку simple/complex;
  • contentRect() та expressionEditRect();
  • scrollZoneRect(numberStart).
Геометрія конкретної картки (наприклад cubeShapeParameterFieldRect(rowRect)) лишається зовнішнім адаптером.
