OpenSCAD Syntax Analysis — Tree Implementation Effort

Without Tree Changes parse-time / pure eval

Implemented in expression.h (evaluator) and/or openscadparser.cpp (parser). No new Operation, ShapeNode, or TreeNode::Type required.
