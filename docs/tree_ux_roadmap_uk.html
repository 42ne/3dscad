Roadmap UX-покращень дерева сцени

Станом на: 2026-06-11. HTML-roadmap оновлено після локального перегляду коду. Markdown-версію навмисно залишено старою.

Заплановані покращення зручності для SceneTreeGraphicsWidget — графічного дерева сцени.

Нотатка після аналізу: навігація з клавіатури, контекстне меню, пошук/фільтр, підсвітка батьків, reset/focus масштабу, scroll/focus до вибраної ноди, invalid-drop feedback і clipboard-дії вже були представлені в roadmap. У цій HTML-версії ці пункти уточнено, а відсутні пропозиції додано окремо: видимі кнопки дій на активній ноді, автоматичний focus при виборі з інших view, і точні команди переміщення без drag/drop.

Критично

1. Навігація з клавіатури

СтатусНе почато
Файлscenetreegraphicswidget.cpp — keyPressEvent
ОписЗараз обробляються переважно Delete/Backspace і кілька mode-клавіш. Додати Up/Down для переходу по видимих сусідах, Left/Right для collapse/expand або переходу parent/child, Enter/F2 для rename, Escape для cancel, Ctrl+0 для reset zoom, F/Space для focus вибраної ноди.
ТестНовий сценарій testrunner: вибір нод клавіатурою, collapse/expand і focus-команда.

2. Collapse / Expand груп

СтатусЧастково — у поточному коді вже є стан collapsed-груп і click-handling; старий roadmap тут застарів.
Файлscenecanvasdraghandler.cpp, scenetreegraphicswidget.cpp, scenetreenoderenderer.cpp
ОписЗберегти наявний click по chevron, але покращити discoverability, keyboard access, анімацію зміни розміру і, за потреби, persistence collapsed-стану.
ТестСценарій testrunner: згорнути групу, додати дітей, розгорнути, перевірити структуру і layout.

Високий пріоритет

3. Контекстне меню по правому кліку

СтатусНе почато
Файлscenetreegraphicswidget.cpp — contextMenuEvent / mousePressEvent
ОписДодати Delete, Rename, Copy, Cut, Paste, Duplicate, Wrap in group, Select Parent, Collapse/Expand, Focus/Fit to node, а також точні Move Before/After/Into команди. Меню має зробити видимими дії, які зараз здебільшого треба вгадувати через hover-підказки або drag.
ТестSynthetic right-click у testrunner для базових команд; ручна перевірка layout меню.

4. Multi-select

СтатусНе почато
Файлscenetreegraphicswidget.h — m_selectedTreeNodeId зараз scalar int
ОписЗамінити на QSet<int> m_selectedNodeIds. Ctrl+click перемикає вибір, Shift+click вибирає діапазон видимих sibling-ноди, bulk-команди працюють через контекстне меню.

5. Пошук / фільтр

СтатусНе почато
ФайлНовий floating overlay або embedded QLineEdit
ОписШукати за назвою, типом, id, номером shape, назвою module і variable. Підсвічувати збіги, приглушувати non-matches, дати next/previous navigation без руйнування контексту дерева.

6. Copy / Cut / Paste / Duplicate

СтатусНе почато
ФайлНові сигнали + clipboard serialization
ОписCtrl+C/X/V/D. Серіалізувати subtree у JSON/MIME для clipboard. Врахувати module-call references, унікальність variable names і правила валідного nesting/drop.

16. Видимі кнопки дій на активній ноді

СтатусНе почато
Файлscenetreenoderenderer.cpp, scenetreegraphicsitems.cpp
ОписКоли нода selected або hovered, показувати компактну смужку дій з іконками Rename, Delete, Duplicate, Collapse/Expand і Focus. Смужка має бути контекстною, щоб дерево не стало візуально перевантаженим.
ТестРучна перевірка primitive, group, module, variable і module-call карток; кнопки не мають перекривати drag handles або expression fields.

Середній пріоритет

7. Підсвітка батьківського ланцюжка

СтатусНе почато
Файлscenetreenoderenderer.cpp — GroupCardItem::paint
ОписКоли вибрана дочірня нода, підсвічувати border батьківських груп вторинним кольором і, можливо, показувати компактний breadcrumb на canvas. Це допоможе орієнтуватися у глибоких сценах.

8. Zoom reset (Ctrl+0) + Fit to node + плавний zoom

СтатусЧастково — smooth zoom і animated focus helper вже є; reset і повна інтеграція з keyboard/menu ще потребують роботи.
Файлscenetreegraphicswidget.cpp, scenetreecanvascontroller.cpp
ОписЗберегти smooth zoom. Додати Ctrl+0 reset, Fit to selected node і відкрити Fit через keyboard/context menu. Де можливо, використати наявний шлях focusSelectedNodeAnimated().

9. Auto-focus selected при програмному виборі

СтатусЧастково — focusSelectedNodeAnimated() існує, але автоматична маршрутизація ще не завершена.
Файлscenetreegraphicswidget.cpp — setSelectedTreeNodeId() і callers синхронізації selection
ОписКоли вибір приходить з viewport, code editor або classic tree, розкрити потрібну ноду в graphics tree, розгорнути collapsed ancestors і анімовано підвести canvas до цілі. Не красти focus під час drag, inline edit або color edit mode.
ТестСценарій: вибрати глибоко вкладений об'єкт з іншого view і перевірити, що graphics tree сам до нього pan/zoom.

10. Візуальний feedback для undo/redo

СтатусНе почато
Файлscenetreegraphicswidget.cpp — refresh() або post-refresh
ОписПісля undo/redo коротко pulse-ити border зміненої ноди або insertion slot, щоб користувач бачив, що саме змінилося.

11. Feedback для invalid drop zone

СтатусНе почато
Файлscenetreegraphicswidget.cpp — dropTargetForToolAt / drop preview rendering
ОписПоказувати червонуватий overlay, no-entry icon і коротку причину, коли drop відхилено. Важливі випадки: root drops, VAR в ordinary group, CALL у parameter lane, drop групи у саму себе або descendant.
ТестНовий testrunner сценарій для invalid drops; ручна перевірка зрозумілості повідомлень.

14. Pan inertia

СтатусГотово (2026-05-25)
Файлscenetreecanvascontroller.cpp, scenetreegraphicswidget.cpp
ОписВідстежувати швидкість pan і плавно сповільнювати після release. Новий press або scroll одразу зупиняє inertia.

17. Точні команди переміщення без drag/drop

СтатусНе почато
ФайлContext menu actions + наявний шлях tree move command
ОписДати menu/keyboard альтернативи для точних структурних змін: Move Before, Move After, Move Into Selected Group, Move Out, Wrap in Union/Difference/Translate. Drag лишається швидким шляхом, команди стають точним шляхом.
ТестНовий testrunner сценарій: викликати move-команди і перевірити структуру дерева, generated code та undo/redo.

Рекомендований порядок реалізації

  1. Pan inertia (#14) — готово.
  2. Polish collapse/expand (#2) — вже є база, потрібні discoverability і keyboard access.
  3. Навігація з клавіатури (#1) — робить дерево схожим на справжній редактор.
  4. Контекстне меню (#3) — відкриває приховані дії з низьким ризиком.
  5. Auto-focus selected (#9) — великий виграш для sync між viewport/code/tree.
  6. Видимі кнопки дій (#16) — роблять базові операції очевидними.
  7. Zoom reset / fit (#8) — маленьке, але корисне завершення наявної focus-логіки.
  8. Підсвітка батьків (#7) — орієнтація в глибоких деревах.
  9. Invalid drop feedback (#11) — замінює мовчазну відмову зрозумілим поясненням.
  10. Точні move-команди (#17) — дають структурне редагування без mouse gymnastics.
  11. Multi-select (#4) — база для bulk operations.
  12. Copy/cut/paste (#6) — clipboard infrastructure.
  13. Empty group affordance (#12) — quick add.
  14. Undo/redo feedback (#10) — polish.
  15. Search/filter (#5) — advanced feature для великих сцен.
  16. Shortcut overlay (#13) — після появи самих shortcut-ів.
  17. VAR/PAR icons (#15) — невелике покращення читабельності.
