3D Viewport UX Improvement Roadmap

Status as of: 2026-06-02.

Planned usability enhancements for ViewportWidget (the 3D preview/render panel).

Already Implemented

FeatureDetails

Perspective / OrthographicToggle via "Ortho" checkbox in viewport

🔴 Critical

1. Frame selection / Zoom-to-fit

Status❌ Not started
Fileviewportwidget.cpp — setSelectedIndex / setSelectedGroupId
DescriptionNo automatic centering on the selected object. Camera always initializes at (0,0,0) target. Add frameSelection() that computes AABB of selected shape/group and adjusts camera distance + target. Bind to toolbar button and F key.

2. Viewport keyboard shortcuts

Status❌ Not started
Fileviewportwidget.cpp — keyPressEvent (not overridden)
DescriptionOverride keyPressEvent: F (frame selection), R (reset view), Ctrl+0 (zoom reset), 1-6 (preset views), W (wireframe toggle), G (grid toggle), B (backend toggle), V (ortho toggle).

🟡 High Priority

3. 3D ray-cast picking in OpenGL mode

Status❌ Not started
Fileviewportwidget.cpp — mousePressEvent / paintGL, viewportglrenderer.cpp
DescriptionPick buffer only from software renderer. Implement glReadPixels-based picking: render shape IDs as colors to offscreen FBO, map pixel to shape index.

4. Camera preset views

Status❌ Not started
Fileviewportcamera.h / viewportwidget.cpp
DescriptionAdd preset buttons: Front, Top, Right, Back, Bottom, Left. Each sets fixed yaw/pitch. Small popup toolbar or radial menu.

5. Scale gizmo

Status❌ Not started
Fileviewportaxisgizmo.h / viewportaxisgizmo.cpp
DescriptionWhen a Scale group is selected, draw scale gizmo (three axis handles + uniform center cube). Detect operation type in pickSelectedTransformAxis().

6. Multi-select in viewport

Status❌ Not started
Fileviewportwidget.h — scalar m_selectedIndex / m_selectedGroupId
DescriptionReplace with QSet<int>. Ctrl+click toggle, Shift+click range.

7. Wireframe rendering mode

Status❌ Not started
Fileviewportglrenderer.cpp / viewportsoftwarerenderer.cpp
DescriptionToggle renders mesh edges instead of (or overlaid on) solid faces. GL: glPolygonMode(GL_FRONT_AND_BACK, GL_LINE). SW: draw un-filled triangles.

8. Viewport context menu

Status❌ Not started
Fileviewportwidget.cpp — contextMenuEvent
DescriptionRight-click currently only pans. Add: Frame Selection, Reset View, Preset Views submenu, Wireframe, Fullscreen, Copy Screenshot.

🟠 Medium Priority

9. Gizmo snapping

Status❌ Not started
Fileviewportaxisgizmo.cpp — drag delta computation
DescriptionSnap toggle: translate deltas snap to 5 mm grid, rotate deltas to 15° increments.

10. Touch / gesture support

11. Viewport screenshot export

12. Selection box / lasso

13. Fullscreen toggle

Implementation Order (Suggested)

  1. Frame selection / Zoom-to-fit (#1) — trivial, unlocks everyday workflow
  2. Viewport keyboard shortcuts (#2) — needed for power users
  3. Ray-cast picking in GL mode (#3) — correctness fix for OpenGL backend
  4. Camera preset views (#4) — low code risk
  5. Scale gizmo (#5) — fills a gap in the existing gizmo system
  6. Wireframe mode (#7) — simple visual toggle
  7. Camera animation (#14) — polish for #1, #4, and camera reset
  8. Context menu (#8) — common expectation
  9. Fullscreen (#13) — small code change, big impact
  10. Screenshot export (#11) — low effort, useful for sharing
  11. Multi-select (#6) — needed for bulk operations
  12. Gizmo snapping (#9) — precise positioning
  13. Viewport overlay toolbar (#15) — maintainability
  14. Touch/gesture (#10) — tablet/laptop users
  15. X-Ray mode (#17) — visual debugging
  16. Selection box/lasso (#12) — bulk selection
  17. Frustum culling (#16) — performance for large scenes
  18. Grid snap toggle (#18) — usability
  19. Measurement tool (#20) — utility
  20. MSAA control (#19) — visual quality
  21. Middle-button orbit (#26) — user preference
  22. Face/edge/vertex snapping (#24) — advanced precision
  23. SSAO (#21) — visual polish
  24. Zoom limits indicator (#25) — minor feedback
  25. LOD (#22) — performance for large scenes
  26. VR (#23) — novelty
