Tree Widget UX Improvement Roadmap

Status as of: 2026-06-11. HTML roadmap refreshed after local code review. The Markdown source is intentionally left at its older version.

Planned usability enhancements for SceneTreeGraphicsWidget (the visual scene tree).

Review note: keyboard navigation, context menu, search/filter, ancestor highlight, zoom reset / fit, scroll-to-selected, invalid drop feedback, and clipboard actions were already represented in the roadmap. This HTML version expands those items and adds the missing usability items found during review: visible node action affordances, auto-focus when selection comes from other views, and precise non-drag move commands.

Critical

1. Keyboard navigation

StatusNot started
Filescenetreegraphicswidget.cpp — keyPressEvent
DescriptionOnly Delete/Backspace and a few mode keys are handled. Add Up/Down to traverse visible siblings, Left/Right to collapse/expand or move parent/child, Enter/F2 to rename, Escape to cancel, Ctrl+0 to reset zoom, and F/Space to focus the selected node.
TestNew testrunner scenario — select nodes with keyboard, verify selection changes, collapse/expand behavior, and focus command.

2. Collapse / Expand groups

StatusPartial — current code already has collapsed group state and click handling; roadmap text was stale.
Filescenecanvasdraghandler.cpp, scenetreegraphicswidget.cpp, scenetreenoderenderer.cpp
DescriptionKeep the existing chevron click behavior, then improve discoverability, keyboard access, animated size transitions, and persistence of collapsed state where useful.
TestNew testrunner scenario — collapse a group, add children, expand, verify structure and visible layout.

High Priority

3. Right-click context menu

StatusNot started
Filescenetreegraphicswidget.cpp — contextMenuEvent / mousePressEvent
DescriptionAdd Delete, Rename, Copy, Cut, Paste, Duplicate, Wrap in group, Select Parent, Collapse/Expand, Focus/Fit to node, and precise Move Before/After/Into commands. The menu should expose existing capabilities that are currently discoverable mostly through hover hints and drag gestures.
TestSynthetic right-click in testrunner for common commands; manual verification for menu layout.

4. Multi-select

StatusNot started
Filescenetreegraphicswidget.h — m_selectedTreeNodeId is scalar int
DescriptionReplace with QSet<int> m_selectedNodeIds. Ctrl+click toggles, Shift+click range-selects visible siblings, and bulk commands work through the context menu.

5. Search / filter bar

StatusNot started
FileNew floating overlay or embedded QLineEdit
DescriptionFilter nodes by name, type, id, shape number, module name, and variable name. Highlight matches, dim non-matches, and provide next/previous result navigation without destroying tree context.

6. Copy / Cut / Paste / Duplicate

StatusNot started
FileNew signals + clipboard serialization
DescriptionCtrl+C/X/V/D. Serialize subtree to JSON/MIME for clipboard. Respect module-call references, variable uniqueness, and valid drop/nesting rules.

16. Visible node action affordances

StatusNot started
Filescenetreenoderenderer.cpp, scenetreegraphicsitems.cpp
DescriptionWhen a node is selected or hovered, show a compact action strip with familiar icon buttons for Rename, Delete, Duplicate, Collapse/Expand, and Focus. Keep the strip contextual so the tree does not become visually noisy.
TestManual visual check across primitive, group, module, variable, and module-call cards; ensure buttons do not block existing drag handles or expression fields.

Medium Priority

7. Parent-ancestor highlight

StatusNot started
Filescenetreenoderenderer.cpp — GroupCardItem::paint
DescriptionWhen a child is selected, draw ancestor group borders in a secondary color and optionally show a compact canvas breadcrumb. This improves orientation in deep nested scenes.

8. Zoom reset (Ctrl+0) + Fit to node + Smooth zoom with inertia

StatusPartial — smooth zoom and animated focus helpers exist; reset and full keyboard/menu integration still need work.
Filescenetreegraphicswidget.cpp, scenetreecanvascontroller.cpp
DescriptionKeep smooth zoom behavior. Add Ctrl+0 reset, Fit to selected node, and expose Fit through keyboard and context menu. Prefer the existing focusSelectedNodeAnimated() path where possible.

9. Auto-focus selected on programmatic selection

StatusPartial — focusSelectedNodeAnimated() exists, but automatic routing is not complete.
Filescenetreegraphicswidget.cpp — setSelectedTreeNodeId() and selection sync callers
DescriptionWhen selection comes from the viewport, code editor, or classic tree, reveal the node in the graphics tree, expand collapsed ancestors, and animate the canvas to the target. Avoid stealing focus during active drag, inline edit, or color edit mode.
TestTestrunner or manual scenario: select a deeply nested object from another view and verify the graphics tree pans/zooms to it.

10. Undo/redo visual feedback

StatusNot started
Filescenetreegraphicswidget.cpp — refresh() or post-refresh
DescriptionAfter undo/redo, briefly pulse affected node borders or insertion slots so the user can see what changed.

11. Invalid drop zone visual feedback

StatusNot started
Filescenetreegraphicswidget.cpp — dropTargetForToolAt / drop preview rendering
DescriptionShow a red-tinted overlay, no-entry icon, and short reason text when a drop is rejected. Useful cases include invalid root drops, VAR into ordinary groups, CALL into parameter lanes, and dropping a group into itself or a descendant.
TestNew testrunner scenario — attempt invalid drops and verify feedback state; manual check for message clarity.

14. Pan inertia (momentum scrolling)

StatusDone (2026-05-25)
Filescenetreecanvascontroller.cpp, scenetreegraphicswidget.cpp
DescriptionTrack pan velocity and decelerate after release. New press or scroll stops inertia immediately.

17. Precise non-drag move commands

StatusNot started
FileContext menu actions + existing tree move command path
DescriptionProvide menu/keyboard alternatives for exact structural edits: Move Before, Move After, Move Into Selected Group, Move Out, and Wrap in Union/Difference/Translate. Drag remains the fast path; commands become the precise path.
TestNew testrunner scenario — invoke move commands and verify tree structure, generated code, and undo/redo.

Low Priority

12. Empty group affordance ("+" button)

StatusNot started
Filescenetreenoderenderer.cpp
DescriptionDashed border + plus icon in empty groups for quick child insertion.

13. Keyboard shortcut cheat-sheet overlay

StatusNot started
Filescenetreegraphicswidget.cpp — new ? handler
DescriptionPopup overlay listing all keyboard shortcuts and mouse gestures.

15. VAR / PAR icon differentiation

StatusNot started
Filescenetreenoderenderer.cpp — VariableCardItem::paint
DescriptionVisual icon difference, such as @ for parameters and $ for local variables, beyond just text labels.

Implementation Order (Suggested)

  1. Pan inertia (#14) — done.
  2. Collapse/expand polish (#2) — existing behavior needs discoverability and keyboard access.
  3. Keyboard navigation (#1) — unlocks editor-like use.
  4. Context menu (#3) — exposes hidden actions with low risk.
  5. Auto-focus selected (#9) — big improvement for viewport/code/tree sync.
  6. Visible node action affordances (#16) — makes common operations discoverable.
  7. Zoom reset / fit (#8) — small, useful completion of existing focus work.
  8. Parent-ancestor highlight (#7) — improves orientation in deep trees.
  9. Invalid drop feedback (#11) — turns silent rejection into understandable feedback.
  10. Precise non-drag move commands (#17) — supports exact editing without mouse gymnastics.
  11. Multi-select (#4) — needed for bulk operations.
  12. Copy/cut/paste (#6) — clipboard infrastructure.
  13. Empty group affordance (#12) — quick add.
  14. Undo/redo feedback (#10) — polish.
  15. Search/filter (#5) — advanced large-scene feature.
  16. Shortcut overlay (#13) — nice-to-have once shortcuts exist.
  17. VAR/PAR icons (#15) — small visual clarity pass.
