🔴 Критичні

1. Frame selection / Zoom-to-fit

Статус❌ Не розпочато
Файлviewportwidget.cpp — setSelectedIndex / setSelectedGroupId
ОписНемає центрування на вибраному об'єкті. Додати frameSelection() — AABB вибраної фігури + підлаштування камери. Клавіша F.

2. Гарячі клавіші в'юпорту

Статус❌ Не розпочато
Файлviewportwidget.cpp — keyPressEvent
ОписF (frame), R (скинути вигляд), 1-6 (пресети), W (wireframe), G (сітка), B (бекенд), V (ортогональна).

🟡 Високий пріоритет

3. Ray-cast picking в OpenGL

Статус❌ Не розпочато
Файлviewportwidget.cpp, viewportglrenderer.cpp
ОписРеалізувати glReadPixels-picking: ID фігур кольорами в offscreen FBO, мапити на індекс.

4. Пресетні вигляди камери

Статус❌ Не розпочато
Файлviewportcamera.h / viewportwidget.cpp

Статус❌ Не розпочато

Статус❌ Не розпочато
Файлviewportwidget.h
ОписЗамінити скалярні поля на QSet<int>. Ctrl+клік, Shift+клік.

Запропонований порядок реалізації

  1. Frame selection (#1) — тривіально, основа роботи
  2. Гарячі клавіші (#2) — для power users
  3. Ray-cast picking (#3) — виправлення OpenGL
  4. Пресетні вигляди (#4) — низький ризик
  5. Scale гізмо (#5) — заповнює прогалину
  6. Wireframe (#7) — простий перемикач
  7. Анімація камери (#14) — полірування
  8. Контекстне меню (#8) — очікування користувачів
  9. Повноекранний режим (#13) — мала зміна, великий ефект
  10. Скріншот (#11) — мало зусиль
  11. Мультивибір (#6) — масові операції
  12. Snap гізмо (#9) — точне позиціонування
  13. Overlay тулбар (#15) — підтримуваність
  14. Touch/жести (#10) — планшети
  15. X-Ray (#17) — візуальне налагодження
  16. Рамка виділення (#12) — масовий вибір
  17. Frustum culling (#16) — продуктивність
  18. Snap до сітки (#18) — зручність
  19. Вимірювання (#20) — утиліта
  20. MSAA (#19) — якість
  21. Орбіта середньою (#26) — вподобання
  22. Snap геометрія (#24) — точність
  23. SSAO (#21) — полірування
  24. Індикатор зуму (#25) — зворотній зв'язок
  25. LOD (#22) — продуктивність
  26. VR (#23) — новинка
